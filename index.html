Biltoo

Biltoo is an image and document viewer written in C++ and Qt 6. It can open single files, directories, and archives. It provides three ways of working with the current set of images or pages: a single-image view, a gallery, and a workspace where items can be arranged freely.

Common image formats, multipage documents, and images inside archives are handled through the same interface. Image sizes and previews are cached to avoid repeatedly decoding large collections.

Features

Viewing and navigation

  • Open files, directories and archives
  • Image view, gallery and freeform workspace
  • Zoom, pan, keyboard navigation and fullscreen
  • Slideshow with image loading during dwell
  • Filmstrip for the current set of images or pages
  • Facing-page and multi-page spreads

Working with images

  • Side-by-side comparison
  • Rotate, flip, crop and colour adjustments
  • Adjustments stay in the session; source files are unchanged
  • Export a workspace as PDF or PNG
  • Cached dimensions and thumbnails
  • Dockable filmstrip, metadata and tool panels

Supported formats

ImagesJPEG, PNG, WebP, TIFF, GIF, BMP, XCF, and other formats supported by the available decoders
DocumentsPDF, EPUB, DjVu (including multipage files)
ArchivesZIP, tar, 7z, RAR, and similar archives; view contained images without manually unpacking

The available formats and features depend in part on the libraries enabled at build time.

Documents and pages

Documents use the same navigation as images. Step through individual pages, use the gallery to see an overview, or place pages on the workspace.

Double view supports facing-page spreads, reading direction, and a configurable number of pages. EPUB documents also support text search.

Install and build

With Nix

nix run github:Grumbel/biltoo

From a source checkout, use nix develop, nix build, or nix run.

With CMake

cmake -B build -S .
cmake --build build
./build/biltoo

Qt 6.9 or newer is required. Optional libraries provide additional codecs, archive support, metadata and persistent caching.

Command line

biltoo [options] [files-or-dirs…]
--fullscreenStart in fullscreen mode
--slideshowStart a slideshow
--debugEnable additional diagnostics

See the README on GitHub for the current build instructions.
