02 / MADE FOR REAL COLLECTIONS

Your files. No fuss.

Biltoo is built around the things you actually do when looking through files—not an endless series of import dialogs.

▦01—04

Browse at speed.

Cached image sizes and previews keep large folders and archives responsive without decoding everything from scratch.

▤02—04

Open the archive.

Look inside ZIP, tar, 7z, RAR, and other supported archives directly. No manual extraction step.

⇄03—04

Make comparisons.

Put images or document pages side by side, use facing-page spreads, or freely arrange a workspace.

◇04—04

Keep originals intact.

Rotate, flip, crop, or adjust colour within your session. The original source files are never modified.

05 / READY WHEN YOU ARE

Bring your
collection.

Biltoo is a free, open-source Linux desktop application. Run it with Nix or build it from source with CMake and Qt.

Explore the source on GitHub ↗
INSTALL BILTOOLINUX / QT 6

Run directly from the GitHub flake:

$ nix run github:Grumbel/biltoo

From a source checkout with the required dependencies installed (Qt 6.9+):

$ cmake -B build -S .
$ cmake --build build
$ ./build/biltoo
